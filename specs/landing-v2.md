# Landing v2 设计简报 / Design brief

参考：https://www.salesmartly.com/（2026-11-02 17:15 UTC+8 研究，仅借鉴结构/密度/视觉节奏；**不复制**其文案、Logo、图片、客户、评价、数字）。

## 参考页观察（约 10.7k px 高，1440 宽）
- 字体：系统无衬线；大标题 56–64px 粗体、居中、两行；强调词用品牌蓝。
- 色彩：浅灰底 #f5f6f8 / 白 交替；中段一整块 **深色区 #04050a**（蓝色光晕径向渐变）承载核心功能；结尾 CTA 为 **蓝色渐变大圆角卡片**；主色饱和蓝 #2563eb 一类。
- 间距：区块 py-24（≈96px），容器 max-w ~1200；卡片圆角 16–24px、细边框、柔和阴影。
- 节奏：每屏都有"视觉物"（产品截图/UI 拼贴/图标阵列），文字永远不单独成屏。

## 分区结构（参考 → ShopPulse 对应）
1. **导航**：Logo + 5 个锚点 + 语言切换 + 登录/免费试用主按钮（sticky、白底毛玻璃）。
2. **Hero**（≈1500px）：小胶囊 eyebrow → 两行居中大标题 → 一段副文 → 双按钮 → 一行"信任条"（参考用客户数/评分——**我们改为真实事实**：中英双语、开源 MIT、一行代码嵌入、多用户隔离、自托管）→ **大幅产品截图拼贴**（真实后台截图为底，四周浮动小卡片：AI 回复、知识库命中、标签、文案生成，用细曲线连接）→ 截图下方一排渠道/场景图标条。
3. **Logo 墙**：参考用客户 Logo——**我们禁止**；替换为"适用场景"图标条（独立站 / 小红书店铺 / 抖音小店 / 朋友圈私域 / 详情页），纯图标+文字，不冒充客户。
4. **痛点区**：居中大标题（问题句）+ 段落 + 深色横条小结 + CTA。ShopPulse：询盘多回不过来、商品资料散落、每个平台都要重写文案。
5. **深色核心功能区**（最重要、最长）：标题 + 01–04 大号数字步骤条；然后 4 张左右交错的大卡片，每张：编号标签、标题、说明、✓ 功能点胶囊、**一个特性值**（参考用 3×/30% 等统计——**我们不用虚构数字**，改用真实特性，如"4 种文案平台""v3 数据隔离""SSE 流式"）+ 右侧 UI 截图/模拟。ShopPulse 四块：
   - 01 AI 客服挂件（流式回复、欢迎语、移动端全屏）
   - 02 知识库 + 商品导入（CSV/JSON，回答引用来源）
   - 03 收件箱 + 标签 + 快捷回复 + 人工接管
   - 04 营销文案（小红书/朋友圈/抖音/详情页）+ 报表（CSV 导出）
6. **渠道/接入条**：标题"一行代码接入"+ 嵌入代码卡 + 图标阵列（网站挂件、后台、CSV、OpenAI 兼容模型），不放第三方品牌 Logo。
7. **解决方案（按角色/场景）Tabs**：4 张带图卡片（店主 / 客服 / 运营文案 / 多店铺团队），图用生成插画或截图。
8. **价值 / 对比区**：替代参考的"安全认证 + 用户评价"——**不放评价**；改为"传统做法 vs ShopPulse"对比表 + 安全要点（会话 Cookie、按用户隔离、自托管、MIT）。
9. **示例定价**：3 档，明确标注"示例价格 / Example pricing"。
10. **FAQ**。
11. **结尾 CTA 大卡**：蓝紫渐变、圆角 32px、双按钮、三个 ✓ 小字。
12. **大页脚**：4–5 列链接（产品 / 功能 / 资源 / 账户 / 关于）、Logo + 一句话、MIT/开源说明、语言切换；不放虚构地址/备案/认证。

## 视觉素材
- 真实截图：screenshots/after-*.png → public/landing/shot-*.png。
- 生成插画（Codex 图像工具，如可用）：hero 背景/插画、4 张功能插画、深色区背景光晕；无文字、无真实品牌 Logo、无人脸。
- 其余用 HTML/CSS 模拟 UI（聊天气泡、标签胶囊、迷你图表）。

## 硬性要求
双语 zh/en（i18n 键）；仅真实功能；无虚构客户/Logo/评价/统计；定价标注示例；npm test 与 build 通过；移动端单列不溢出。
